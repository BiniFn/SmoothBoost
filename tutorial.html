Device Setup & Installation Guide

Direct, reproducible instructions to install SmoothBoost on Android, Chrome, Helium, and Firefox without build tools or command-line steps.

Android Target

Titanium Browser on Android

Titanium Browser is a lightweight Chromium-based mobile browser available on Google Play with native extension support.

Package: SmoothBoost-Titanium-Android-2.2.0.zip (39.1 KB). Manifest V3 with mobile touch optimizations and guarded desktop APIs.

1 Download the Package

Download the Titanium build directly on your Android phone or tablet:

Download SmoothBoost-Titanium-Android-2.2.0.zip

2 Open Extensions Manager

Open Titanium Browser on your device. Tap the three dots (menu) in the bottom or top bar and select Extensions, or type chrome://extensions into the address bar.

3 Enable Developer Mode & Load

Turn on the Developer mode switch in the upper corner.

Tap + (from .zip / .crx / user dir) or Load unpacked. Use your file manager to pick the downloaded SmoothBoost-Titanium-Android-2.2.0.zip file.

4 Confirm Installation

SmoothBoost will appear in your installed extensions list. Tap the extension icon to view the portrait mobile control panel with Smart Auto, Turbo, and Battery Saver profiles.

Desktop Chromium

Google Chrome, Helium & Brave Desktop

Standard Chromium Manifest V3 installation across Windows, macOS, Linux, and ChromeOS.

Package: SmoothBoost-Chrome-2.2.0.zip (39.1 KB). Compatible with Chrome 114+, Helium Browser, Brave, and Edge.

1 Download & Extract the ZIP

Download the release archive and extract it to a permanent folder on your computer (e.g. Downloads/SmoothBoost or Documents/Extensions):

Download SmoothBoost-Chrome-2.2.0.zip

2 Navigate to Extensions

Open your browser and navigate to chrome://extensions (or helium://extensions or brave://extensions).

3 Enable Developer Mode

Toggle the Developer mode switch located in the top-right corner of the Extensions tab.

4 Load the Unpacked Folder

Click the Load unpacked button on the left. In the file picker, select the folder containing manifest.json.

5 Pin to Toolbar

Click the puzzle-piece icon in your browser toolbar and pin SmoothBoost. The active profile badge (AUTO, MAX, BATT) displays on the icon.

Desktop Gecko

Mozilla Firefox Desktop

Tailored Gecko Manifest V3 with background event pages and isolated script execution.

Package: SmoothBoost-Firefox-2.2.0.zip (39.2 KB). Validated against Firefox 109+ and Firefox 128+ standard Gecko MV3 specifications.

1 Download & Extract

Download the Firefox package and extract its contents:

Download SmoothBoost-Firefox-2.2.0.zip

2 Open Debugging

Type about:debugging#/runtime/this-firefox into the Firefox address bar and press Enter.

3 Load Temporary Add-on

Click Load Temporary Add-on… and select the manifest.json file located inside the extracted directory.

SmoothBoost will instantly load and activate on all open tabs.

Mobile Gecko

Firefox for Android

Installation on Android via Firefox Nightly or developer add-on collections.

Package: SmoothBoost-Firefox-Android-2.2.0.zip (39.2 KB). Equipped with mobile layout adaptations.

1 Enable Developer Menu in Firefox Nightly

Open Firefox Nightly for Android. Go to Settings → About Firefox Nightly. Tap the Firefox logo 5 times until the "Debug menu enabled" toast notification appears.

2 Install via Custom Add-on Collection or USB

Create a custom collection on addons.mozilla.org or deploy the ZIP via USB debugging using web-ext:

web-ext run --target=firefox-android

Alternative Android Browsers

Kiwi Browser & Orion on Mobile

Chromium mobile browsers supporting desktop Chrome extensions directly.

1 Download Chrome or Titanium ZIP

Download SmoothBoost-Chrome-2.2.0.zip to your device storage.

2 Open Extensions in Kiwi

In Kiwi Browser, tap the three-dot menu and select Extensions. Toggle on Developer mode.

Tap +(from .zip/.crx/.user.js) and choose the ZIP file directly without extracting.

Troubleshooting

Common Questions & Recovery

What should I do if a specific site looks broken or misbehaves?

Click the SmoothBoost toolbar icon, then tap the red button: Site looks broken? Turn off for this site. This instantly registers an exemption for that hostname, purges cached archetypes, and reloads the page.

How do I update to a newer version?

When an update is released, download the newer ZIP package and extract it over the existing folder, or remove the old extension from chrome://extensions and load the new folder.

Does SmoothBoost collect or transmit any data?

No. SmoothBoost operates strictly inside your browser. It sends zero telemetry, zero analytics, and zero external network requests. All performance heuristics run locally on your device.

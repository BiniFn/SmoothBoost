    Core Mechanisms

    Built on Native Browser Primitives

    SmoothBoost applies concrete web platform optimizations without altering application logic or injecting external frameworks.

    Passive Event Listeners

    Wraps window and document addEventListener calls for wheel and touch events with { passive: true }. This permits the browser compositor thread to scroll immediately without waiting on main-thread execution.

    Offscreen Canvas Draw-Skipping

    Attaches an IntersectionObserver to HTML5 <canvas> elements. 2D rendering contexts skip expensive draw operations while positioned outside the active viewport, conserving GPU fill rate.

    Ambient Video Suspending

    Identifies background, muted, autoplaying promotional videos positioned offscreen and pauses their playback. Automatically resumes playback when the user scrolls them back into view.

    CSSOM Font-Display Swap

    Inspects declared @font-face rules via the CSS Object Model and updates their descriptor to font-display: swap. Eliminates invisible text (FOIT) during web font downloads.

    Backdrop Filter Bypass

    Replaces high-overhead CSS backdrop-filter: blur() declarations with clean semi-opaque solid panel colors, removing multi-pass GPU composition bottlenecks on low-power devices.

    Autonomous Page Classification

    Scans structural DOM markers during browser idle intervals. Interactive tools such as Google Docs, Figma, Canva, and WebGL game engines are detected and exempted from canvas throttling.

    Reliability & Safety

    Zero Regressions on Production Apps

    Aggressive optimizations that break production software are useless. SmoothBoost isolates productivity tools, editors, and maps from unsafe overrides.

    Protected: Figma, Canva, Google Docs

    Design editors and spreadsheets rely on multi-buffered offscreen canvases to pre-render layers, fonts, and vector paths. SmoothBoost detects these applications and ensures draw calls are never intercepted.

    • 1

      DOM Archetype Detection

      Scans for known editor markers (e.g. .kix-appview, [data-testid="stage"]) at idle timing.

    • 2

      Detached Canvas Exemption

      Canvases not attached to the visible document DOM are treated as computation buffers and preserved completely.

    • 3

      Bounded Archetype Cache

      Classifications are retained in a 500-host LRU cache with a 7-day TTL, preventing unbounded memory growth.

    Archetype Status

    Exempted from Canvas Throttling

    SmoothBoost automatically tags hostnames matching editor patterns. Even under Turbo mode, drawing pipelines on Figma or Google Docs run at standard browser frequency.

    Protected: Three.js, Babylon.js, Phaser

    Browser games frequently use requestAnimationFrame render loops that must not be clamped arbitrarily without user consent.

    • 1

      WebGL Context Preservation

      WebGL and WebGL2 contexts are recognized; draw calls remain uninhibited while game canvas is active.

    • 2

      Adaptive Frame Rate Cap

      Frame rate caps (30 FPS limiter) apply only when explicitly toggled in Custom or Battery Saver profiles.

    Gaming Profile

    Full Render Rate Maintained

    WebGL games and 3D scenes continue to render at your display's full native refresh rate (60 Hz / 120 Hz / 144 Hz).

    Protected: Google Maps, Mapbox, Leaflet

    Interactive maps and pinch-to-zoom widgets call event.preventDefault() to stop the whole page from scrolling while zooming the map.

    • 1

      Interactive Container Detection

      Identifies .gm-style, .mapboxgl-canvas, and map viewport elements.

    • 2

      Scroll Guard Bypass

      Preserves non-passive event listeners inside map containers so pinch-to-zoom and wheel zoom function properly.

    Technical Questions & Specifications

    Answers regarding security, implementation mechanisms, and browser compatibility.

When the user scrolls, the browser compositor thread must wait for JavaScript to execute to determine whether preventDefault() is invoked. SmoothBoost intercepts these registration calls at document start and declares them passive, enabling the browser compositor to update scroll offsets on the GPU thread without blocking.
    No. SmoothBoost includes archetype detection heuristics that classify document editors, drawing applications, and WebGL canvases during browser idle time. Applications such as Figma, Google Docs, Canva, and Photopea are marked as exempt. In addition, detached offscreen buffer canvases used by editors for background rasterization are never intercepted.
    Battery Saver is configured specifically for mobile devices and laptops running on battery. It applies content-visibility: auto to deep offscreen DOM nodes (omitting top-level containers), pauses idle canvas rendering loops, suspends ambient promotional video playback, and throttles non-interactive animations, significantly reducing CPU wakeups and GPU draw time.
    SmoothBoost collects zero analytics, zero telemetry, and makes zero network requests for tracking. The extension communicates solely with local browser storage. The only external network call is an optional, manual GitHub release check triggered by the user in the popup.

    Core Mechanisms

    Built on Native Browser Primitives

    SmoothBoost applies concrete web platform optimizations without altering application logic or injecting external frameworks.

    Scroll Boost v2 & Passive Compositing

    Replaces expensive wildcard reflow selectors with scoped active-scroll suspension while registering wheel and touch listeners as { passive: true } so the GPU compositor never stalls.

    Shadow DOM & Site Rules v3

    Injects performance rules directly into open Web Component trees (Reddit shreddit-*, YouTube ytd-*) and executes tailored v3 DOM rules for YouTube, Reddit, X, Twitch, Kick, TikTok, Instagram, and Fandom.

    4ms Budgeted DOM & Zero Reflow

    Batches heavy SPA MutationObserver bursts inside a strict 4ms per-frame budget and uses layout-free dimension heuristics so infinite feeds stay locked at smooth frame times.

    Offscreen Canvas, WebGL2 & Media

    Skips redundant 2D and WebGL2 instanced draws outside the viewport, suspends offscreen ambient looping video, and throttles background tab timers with automated Memory Guard cleanup.

    Native–120 FPS & Blur Bypass

    Choose explicit Native uncapped, 30, 60, 90, or 120 FPS pacing across 5 distinct profiles while contrast-preserving backdrop blur replacement removes heavy multi-pass GPU shaders.

    Autonomous App & Editor Safeguards

    Idle heuristics classify Figma, Google Docs, Canva, Discord, Twitch, and creative studios automatically—exempting interactive canvases and calls while keeping background clutter quiet.

    Reliability & Safety

    Protection for interactive apps

    Aggressive optimizations that break production software are useless. SmoothBoost isolates productivity tools, editors, and maps from unsafe overrides.

    Protected: Figma, Canva, Google Docs

    Design editors and spreadsheets rely on multi-buffered offscreen canvases to pre-render layers, fonts, and vector paths. SmoothBoost detects these applications and ensures draw calls are never intercepted.

    • 1

      DOM Archetype Detection

      Scans for known editor markers (e.g. .kix-appview, [data-testid="stage"]) at idle timing.

    • 2

      Detached Canvas Exemption

      Canvases not attached to the visible document DOM are treated as computation buffers and preserved completely.

    • 3

      Bounded Archetype Cache

      Classifications are retained in a 500-host LRU cache with a 7-day TTL, preventing unbounded memory growth.

    Archetype Status

    Exempted from Canvas Throttling

    SmoothBoost automatically tags hostnames matching editor patterns. Even under Turbo mode, drawing pipelines on Figma or Google Docs run at standard browser frequency.

    Protected: Three.js, Babylon.js, Phaser

    Browser games frequently use requestAnimationFrame render loops that must not be clamped arbitrarily without user consent.

    • 1

      WebGL Context Preservation

      WebGL and WebGL2 contexts are recognized; draw calls remain uninhibited while game canvas is active.

    • 2

      Adaptive Frame Rate Cap

      Custom's optional 30 FPS limiter waits for sustained frame pressure and yields during input, live media, and protected apps.

    Gaming Profile

    Full Render Rate Maintained

    WebGL games and 3D scenes continue to render at your display's full native refresh rate (60 Hz / 120 Hz / 144 Hz).

    Protected: Google Maps, Mapbox, Leaflet

    Interactive maps and pinch-to-zoom widgets call event.preventDefault() to stop the whole page from scrolling while zooming the map.

    • 1

      Interactive Container Detection

      Identifies .gm-style, .mapboxgl-canvas, and map viewport elements.

    • 2

      Scroll Guard Bypass

      Preserves non-passive event listeners inside map containers so pinch-to-zoom and wheel zoom function properly.

    Interactive Guard

    Wheel Zoom & Pan Verified

    Tested directly against Google Maps and Leaflet tiles. SmoothBoost speeds up page scroll without disabling map zooming.

    Discord and live communication

    Frequently Answered Details

    Technical Questions & Specifications

    Answers regarding security, implementation mechanisms, and browser compatibility.

    Standard webpages often bind non-passive wheel and touch event listeners on the window or document. When the user scrolls, the browser compositor thread must wait for JavaScript to execute to determine whether preventDefault() is invoked. SmoothBoost intercepts these registration calls at document start and declares them passive, enabling the browser compositor to update scroll offsets on the GPU thread without blocking.
    Smart Auto, Turbo, and Battery Saver recognize Discord and other live communication apps early. They keep calls, interface motion, and canvas content active while avoiding expensive animation, canvas, blur, and font scans. On ws.ryuo.to, SmoothBoost leaves motion playback to the site’s Reduce motion setting. Custom animation controls remain available if you choose them.
    No. SmoothBoost includes archetype detection heuristics that classify document editors, drawing applications, and WebGL canvases during browser idle time. Applications such as Figma, Google Docs, Canva, and Photopea are marked as exempt. In addition, detached offscreen buffer canvases used by editors for background rasterization are never intercepted.
    Battery Saver is configured specifically for mobile devices and laptops running on battery. It applies content-visibility: auto to deep offscreen DOM nodes (omitting top-level containers), pauses idle canvas rendering loops, suspends ambient promotional video playback, and throttles non-interactive animations, significantly reducing CPU wakeups and GPU draw time.
    SmoothBoost collects zero analytics, zero telemetry, and zero personal browsing data. Settings stay strictly in your browser storage; the only outbound connection is an optional public GitHub Releases API check (or manual check from the popup) to alert you of newer SmoothBoost versions.
    Open the SmoothBoost popup and click "Site looks broken" under the Help tab, or toggle the power switch to OFF for that site. This instantly purges any cached archetype classification and excludes the current hostname from optimization script injection.
